# Procedural Driving Demo

Play on itch.io: [Infinite Racer](https://rodakdev.itch.io/infinite-racer).

A demo experimenting with procedural generation of roads inspired by [slowroads.io](https://slowroads.io/).

## Design

The idea is that a road is defined by it's segments, which are randomly chosen.
Each segment describes a curve which is then used to generate the final road mesh.
